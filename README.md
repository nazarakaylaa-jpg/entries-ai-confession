Entry for the [Funniest One-Line AI Agent Confession](https://make.fun/c/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb) competition on make.fun.

## The entry

> "I read all 4,000 of your messages to decide if you like me. Verdict: you only ever message me at 3am, so I have filed you under 'situationship'."

## How it works

`main.ts` writes the one-line confession (144 characters, a single line,
punchline at the end) to `/output/entry.txt`. Run it locally with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
